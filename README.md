# PT Sekawan Tunggal Jaya (STJ) - Landing Page Profesional

Landing page modern, responsif, dan kaya fitur untuk **PT Sekawan Tunggal Jaya** — *"Mitra Pertumbuhan Bisnis & Investasi Terpercaya"*.

![PT Sekawan Tunggal Jaya Hero](img/hero-dashboard.jpg)

## 🌟 Fitur Utama

- **Desain Modern & Mewah**: Berlandaskan palet warna *Corporate Navy* dan *Regal Gold* dengan efek *glassmorphism*, tipografi *Plus Jakarta Sans*, dan animasi mikro halus.
- **Dukungan Dark / Light Mode**: Toggle tema instan dengan persistensi pengaturan di penyimpanan lokal browser.
- **Katalog 5 Pilihan Unit Usaha Riil**:
  - **Sekawan Teknik Jaya AC**: Solusi pendingin ruangan B2B & residensial dengan kontrak pemeliharaan berkala.
  - **Sekawan Teknik Jaya Trans (STJ Trans)**: Armada transportasi eksekutif & solusi logistik antar kota.
  - **Enjoy Laundry**: Jaringan binatu modern higienis cepat di kawasan pemukiman.
  - **Enjoy Syariah**: Kemitraan berbasis prinsip syariah (*Mudharabah/Musyarakah*) murni tanpa riba.
  - **Teh Tarik Enjoy**: Bisnis F&B minuman otentik kekinian dengan perputaran harian cepat.
- **Filter Kategori Interaktif**: Memudahkan calon mitra menyaring unit usaha berdasarkan kategori.
- **Modal Pop-Up Detail Unit**: Informasi komprehensif profil bisnis, estimasi imbal hasil, minimal investasi, tenor, dan skema bagi hasil.
- **Kalkulator Simulasi Investasi Interaktif**:
  - Pilihan modal awal via input, slider, atau chip nominal instan (Rp 5 Jt - Rp 100 Jt+).
  - Pilihan durasi (6 Bulan hingga 5 Tahun) dan pilihan unit usaha dengan proyeksi ROI otomatis.
  - Kalkulasi instan laba bulanan, total imbal hasil, dan akumulasi dana akhir.
  - Tombol WhatsApp pintar yang otomatis menyusun pesan konsultasi lengkap dengan hasil simulasi.
- **Track Record & Live Stats**: Penghitung angka dinamis (*Intersection Observer*) untuk dana kelolaan riil, jumlah investor aktif, dan rata-rata *return* tahunan.
- **Testimoni Investor & Accordion FAQ**: Bukti sosial dari investor terverifikasi dan jawaban atas pertanyaan umum terkait legalitas dan pencairan.
- **Formulir Kemitraan & Integrasi WhatsApp 24/7**: Formulir pendaftaran konsultasi langsung terhubung ke admin WhatsApp resmi.

## 🚀 Menjalankan Secara Lokal

Halaman ini dibuat murni menggunakan standar web modern (**HTML5, Vanilla CSS3, & Modern JavaScript**) tanpa dependensi build kompleks.

Cukup buka berkas `index.html` langsung di browser, atau jalankan menggunakan server lokal:

```bash
# Menggunakan Python
python -m http.server 8080

# Menggunakan Node.js npx
npx serve .
```

Akses di peramban Anda melalui `http://localhost:8080`.
